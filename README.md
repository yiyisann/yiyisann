# Hi, I'm Ethan

My background is hospitality partnerships and TravelTech operations in Japan. I build practical tools for turning information into a clear next step.

That background shapes the problems I choose. I define the workflows and data boundaries, collaborate with Claude Code and Codex on prototyping, implementation, debugging and review, and make the final acceptance decisions.

**My flagship is Personal Command Center:** a desktop workspace for reviewing information, reading in context, and explicitly saving what to do next. As of **27 October 2026**, PCC 0.17.0 has completed formal installed-app acceptance on Mac and Windows. [Watch the historical 0.16.1 browser walkthrough](https://github.com/yiyisann/ethan-project-showcase/blob/main/DEMO.md): read a source, explicitly save a waiting action, and return after reload. A new 0.17.0 native recording is not provided; [evidence and remaining limits](https://github.com/yiyisann/ethan-project-showcase/blob/main/EVIDENCE.md) distinguish the capture from current acceptance.

Two supporting projects explore scoped, read-only AI context and a focused Windows recognition overlay. [Browse the projects](https://github.com/yiyisann/ethan-project-showcase) or [run a small evidence-cache example](https://github.com/yiyisann/evidence-cache-demo).

I care about retaining useful facts when refresh fails, keeping suggestions separate from user decisions, and stating what has actually been verified.

**From hospitality to a proposed project:** My hotel-partnerships experience informs a public-source briefing for hotel visits: key facts with source links, conflicting claims, missing information and questions to confirm with the hotel. This is the direction I plan to explore during Built with Claude Japan 2026, not a finished competition product. PCC is prior work demonstrating how I build. The proposed briefing would use public information, without employer or customer confidential material.
